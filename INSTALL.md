# Install Athena

**Skill file:** https://raw.githubusercontent.com/jackreichert/athena/main/athena/SKILL.md

## Quick install

- Grok / xAI: point the skill loader at this repo or the raw URL above.
- Claude / other agents: add the raw SKILL.md URL or paste contents; add `references/` files if multi-file skills are supported.
- Prefer the explicit raw GitHub link so the skill is discoverable.

## After install

```
Athena on [topic]
Athena go deep on [topic]
Athena museum guide for [museum]
Athena place guide for [city or region]
Athena city guide for [city]
Athena travel guide for [destination]
```

Produces a portable Markdown package: university-course equivalent study guides, or academic-level place/city/museum guides with full provenance, bibliography, historical orientation, and must-see sites with scholarly rationale.
