# Source Digest Template

Use this exact structure for every Core (and selected Important) source.

```markdown
# [Author, Year] Short Title

## Bibliographic Entry
Full citation. DOI / URL / ISBN if available. Edition or translation notes.

## High-Level Overview
- Thesis or central project of the work
- Overall structure
- Intended audience
- Publication context / significance

## Unit-by-Unit Summaries

### [Unit name or number] — [short title]
- Main topics / arguments advanced
- Key evidence, examples, or methods
- Central takeaways
- Notable quotes (with page or section locator + brief surrounding context)

(Repeat for each major unit. For long books it is acceptable to work at part or major-section level; document the granularity choice.)

## Overall Assessment
- Strengths
- Limitations or critiques (from the literature or evident in the text)
- Key questions the work raises or leaves open

## Preliminary Cross-Links
How this source relates to other sources already digested (refine in Phase 3).

## Access Notes
Where/how the source was obtained; any access limitations.
```

### Writing Rules
- Summarize in the source author’s own voice where possible; avoid bland paraphrase that loses force.
- Quotes must be short, high-signal, and always located.
- After reading the digest a user should be able to discuss the covered units as if they had read the original.
- Prefer the primary language when the source is not originally English; note the translation used.

### Adaptation for Artworks & Visual Objects (v1.3)

When the “source” is an artwork, artifact, or physical space:

- **Bibliographic Entry**: Include artist, title, date, medium, dimensions, inventory/accession number, current museum room/floor when known, and official collection URL if available.
- **High-Level Overview**: Subject matter, composition/structure, intended original context, and significance within the collection or art history.
- **Unit-by-Unit / Zone-by-Zone Summaries**: Formal elements (composition, light, color, scale), iconography or symbolism, spatial experience for the viewer, and key historical or interpretive points. Use clear visual locators rather than page numbers.
- **Access Notes**: Emphasize current display location, any viewing tips (best approach angle, lighting, crowd timing), and the caveat that hangings can change.

Retain the overall Assessment, Cross-Links, and structure so digests remain parallel and navigable.
