# Athena Changelog

Process version history for the Athena skill. The agent does not need this file at runtime; it is for maintainers and package users.

**Current process version:** 1.35 (2026-09-28)

## Selected entries

- **1.35 (2026-09-28):** Bounded apparatus / bibliography pass on the shared research spine. After a draft Core list exists, mine the scholarly apparatus (bibliographies, recommended-reading chapters, editors’ notes) of Core works that actually have one; cap extraction; log provenance as *cited in [Core work]*; do not auto-promote to Core and do not copy entire bibliographies. New `01-sources.md` subsection **Apparatus & Bibliographies Consulted**. New on-request Phase 1b against a finished package produces `01c-citation-network.md` (triggers: “expand from bibliographies,” “citation network,” “next ring from Core”) without reopening the digest gate unless ranking is explicitly reopened. Deep mode expects a richer first-assembly pass; Survey/Standard keep the light cap. Theme bibliographies may absorb apparatus citations that land on that theme. Shared-spine change — not a new adaptive application. Updated SKILL.md (Principle 2, Core Value, Phase 1 / 1b, Phase 5, constraints, frontmatter triggers), mode-survey.md, mode-standard.md, mode-deep.md, directory-layout.md, DEVELOPMENT.md, and the public README.
- **1.34 (2026-09-22):** Digest template adds **How to read this source (first encounter)** under Pre-Reading Context. Required for long, composite, or formally odd Core sources (letter collections, notebooks, fragment corpora, multi-book treatises, case clusters, paper+supplement packages); lean or omit for a short continuous treatise. Distinguishes a named first-pass *route* from Watch-fors (attention cues) and from `02-digests.md` (order across sources). Deep mode may add a short second-pass route after the Full Brief when the first pass postponed material. SKILL.md Phase 2 / Phase 5 spot-check updated; mode files and directory-layout note the section. Public README updated. No new adaptive application.
- **1.33 (2026-09-06):** Fourth adaptive application — `references/practical-guides.md` (Practical Guides / Hands-on Course Supplements). Orthogonal to Survey / Standard / Deep. Loaded on request or when the topic is already a lab / studio / practicum / skills course; **not** auto-added to ordinary study-guide runs. Companion lives under `practical/` as a task sequence with declared guidance states (modeled / faded / independent / exploratory-with-scaffolds), required task sections, and extra Phase 5 gates. Grounded in a Discovery-first Deep package on practical-guide pedagogy (cognitive apprenticeship, 4C/ID, worked examples and fading, Schön’s practicum, UbD / constructive alignment, lab-genre critique, checklists as performance support). Updated SKILL.md load rules, Adaptive Applications, Phase 0/4/5, frontmatter triggers, directory-layout.md, DEVELOPMENT.md, and the public README.
- **1.32 (2026-08-25):** After research and thematic synthesis are complete (post-Phase 3, before packaging), decide the primary university department or program that would most naturally house a course of this kind (based on Core sources, mined syllabi, thematic focus, and learning outcomes). Record it in both `00-scope.md` and the package `README.md`. If genuinely interdisciplinary, name primary + secondary affiliations. Updated Phase 0 note, Phase 3 decision step, Phase 4 required fields, and directory-layout.md descriptions. Public README also updated to surface the new departmental-home field.
- **1.31 (2026-08-23):** Place / location / travel guides now explicitly require a historical overview (layered chronology or key periods). For museum / collection guides the historical overview is required only when the museum itself is historically important (as building, institution, or site); otherwise optional so the focus can remain on collections and artworks. Updated `references/place-guides.md` and the Adaptive Applications short rules in SKILL.md.
- **1.30 (2026-08-19):** Integrity audit strengthened. (1) Top-level index files themselves (`02-digests.md`, `03-themes.md`) must be complete and accurate — not stubs. (2) Every Core *and* every Important source must have a corresponding complete digest file (previously “Core and selected Important”). (3) Every theme topic listed in `03-themes.md` must have a complete theme file. Updated Guiding Principle 9, Phase 2 completeness gate, Phase 5 audit steps, Output Conventions, Constraints, mode-standard.md, mode-deep.md, and directory-layout.md.
- **1.29 (2026-08-19):** Post-creation package integrity audit. After Phase 4 assembly, a mandatory active filesystem audit verifies that every file referenced by indexes (`03-themes.md`, `02-digests.md`, README lists, etc.) actually exists on disk and meets structural requirements (required sections present). Missing or incomplete theme/digest files force an immediate return to Phase 3 or Phase 2, completion of the missing content, and re-audit. Overview/index files without their referenced content no longer constitute a finished package. Strengthened Guiding Principle 9, fully rewrote Phase 5 as an executable audit with explicit return-to-phase rules, updated Output Conventions and Constraints, and mirrored the gate in mode files and directory-layout.md. Addresses recurring incomplete deliveries where themes/digests overviews existed but the individual files did not.
- **1.28 (2026-08-18):** Provenance-first refinement. Rich metadata + durable links (institution, course, year/term, URL or stable identifier, retrieval date, short extraction note; prefer archive.org when fragile) are now the required default for every consulted syllabus. Full Markdown archival under `source-materials/` is optional and recommended only for especially valuable or unstable syllabi (and short accessible sources when relevant/rights-permissive). Softens the 1.27 preference while retaining the folder, header convention, and empty-dir cleanup. Updated Guiding Principles, Phase 1, Core Value notes, Output Conventions, Phase 5 QA, and directory-layout.md.
- **1.27 (2026-08-18):** Source-materials archival. When feasible and rights-permissive, keep clean Markdown reformats of consulted syllabi (and relevant short accessible sources) under a new `source-materials/` folder (with `syllabi/` and optional `sources/` subfolders). Each archived file carries a header with original URL, institution/course, retrieval date, and reformatting notes; local copies are linked from the Syllabi & Discovery Sources Consulted section of `01-sources.md`. Makes the discovery/provenance trail self-contained and resistant to link rot. Updated Guiding Principles, Phase 1, Core Value notes, Output Conventions, Phase 5 QA, and directory-layout.md. Empty-directory cleanup rule extended to `source-materials/`.
- **1.26 (2026-08-17):** Final packaging cleanup. Create the `images/` directory only when at least one image is actually included; as a last step before zipping, remove any empty directories (most commonly an unused `images/` folder). Updated Output Conventions, Phase 5 QA, and directory-layout.md. Keeps delivered packages free of empty clutter.
- **1.25 (2026-08-16):** Themes now require an **Across the Sources: What Is Easy to Miss** checklist (typically 4–7 concrete bullets on structural/formal parallels, devices that change function across texts, inter-source tensions, or hinges visible only in comparison). This is the thematic parallel to the digest “After Reading: What Is Easy to Miss” section and the museum dual-layer idea. Updated directory-layout.md, mode-standard.md, mode-deep.md, and the themes guidance in SKILL.md. Forces theme narratives to surface relational observations rather than elevated parallel summaries.
- **1.24 (2026-08-16):** Added required “After Reading: What Is Easy to Miss” checklist at the head of the Full Brief (immediately after Summary). This is the literary/philosophical parallel to the museum dual-layer (Unit/Zone + Period-Specialist Analysis): a short, concrete, text-grounded list of structural hinges, formal choices, and tensions that careful first-time readers frequently overlook. Keeps the anti-reductive stance while giving the student an explicit post-encounter checkpoint. Updated digest-template.md Writing Rules and density language accordingly.
- **1.23 (2026-08-16):** Digest and theme density improvements. Raised the quality bar against high-level shorthand that functions mainly as TA reminders. Key changes: (1) Pre-Reading Context now includes optional/required “Reading posture / Watch-fors” (genre-aware, non-spoiling); (2) Unit-by-Unit sections require a short “Function in the arc” note plus stronger high-signal quotes with locators and why-pivotal context; (3) denser Assessment language and explicit density expectation in Writing Rules; (4) formalized recommendation for `author-context.md` (lean intellectual biography + relevant reception) on single-author literary/philosophical packages for consistency (Plato had one; Poe did not); (5) corresponding updates to mode-standard.md, mode-deep.md, and directory-layout.md. Themes should synthesize across sources rather than remain parallel summaries. Structure (Pre/Summary/Full Brief) unchanged and still preferred.
- **1.22 (2026-08-16):** Added second Discovery-first adaptive application: `references/legal-case-guides.md` (Legal Case Deep Dives / Case Method). Grounded in a Deep Athena run on the pedagogy of the Langdellian case method, case briefing (IRAC/FIRAC), Socratic dynamics, and modern contextual/problem-solving reforms. Updated SKILL.md loading rules, Adaptive Applications section, frontmatter triggers, and resource pointers.
- **1.21 (2026-08-16):** Added first new adaptive application after following the Discovery-first rule: `references/science-paper-guides.md` (Scientific Paper Deep Dives). Grounded in a Deep Athena run on how strong scientific training programs teach reading, critique, and positioning of primary research papers (CREATE strategy, Carey et al. ten rules, Swales CARS, Users’ Guides tradition, etc.). Updated SKILL.md Adaptive Applications section and resource pointers.
- **1.20 (2026-08-16):** Modularized the skill structure. Extracted package-shape (mode) specifics into `references/mode-survey.md`, `mode-standard.md`, `mode-deep.md` (deltas only). Extracted Adaptive Applications (place/museum/location guides) into `references/place-guides.md`. Moved full changelog out of the runtime SKILL.md into this top-level CHANGELOG.md. Added DEVELOPMENT.md documenting the modular contract, progressive-disclosure rules, and how to expand the skill cleanly. SKILL.md is now the shared spine only (~190 lines). This keeps the agent’s loaded context lean while preserving all behavior. DEVELOPMENT.md now requires a Discovery-first step (run Athena’s own Deep/Survey process on the pedagogy of the target domain) before adding any new mode or adaptive application.
- **1.19 (2026-08-16):** Added **images** for visual primary sources (artworks, architecture, maps, diagrams) when they enhance understanding — required for major museum works, strongly recommended for place guides. Prefer official/public-domain sources; store under `images/` with relative links, captions, and official collection links. Added **output format** options: default Markdown optimized for Obsidian; optional EPUB when requested. Updated Adaptive Applications (museum + place), Phase 0, Phase 2 digests, Output Conventions, directory layout, and digest template.
- **1.18 (2026-08-16):** Introduced explicit **Survey package shape** (sources + themes foundation; digests deferred) alongside Standard and Deep. Softened the completeness gate so Survey packages are exempt by design. Added `02-digests.md` (index + recommended reading order) for Full packages. Updated Phase 0 to require an explicit decision on whether digests are in scope, Phase 2 to skip cleanly for Survey, citation rules in themes to work with or without digests, directory layout, QA, and Output Conventions. Fixes the force-fit that muddled “undergrad survey first, digests later” requests (e.g. Poe). The rigorous research spine (syllabi, provenance, ranked sources, themes with citations, further reading) remains identical across all three shapes.
- **1.17 (2026-08-15):** Expanded Adaptive Applications from museum/cultural-site guides to full **place / location / travel guides** at academic depth (cities, regions, historic landscapes). Modeled on Blue Guides, university “History of [City] / Biography of a City” syllabi, layered city histories, and cultural-landscape practice. Location guides start with syllabi when available, otherwise highest-quality scholarly sources; full provenance and bibliography required; historical orientation + must-see sites with scholarly rationale + practical itineraries. Museum specializations retained. Triggers updated to include place/city/travel guides.
- **1.16 (2026-08-15):** Restructured primary-source digests into three explicit parts: **Pre-Reading Context** (orientation before reading, non-spoiling), **Summary** (standalone reference when not reading the source), and **Full Brief (Post-Reading)** (dense check after reading to catch what might be missed in the greater conversation). Explicit anti-reductive / anti-SparkNotes stance: digests help the reader see more and not miss important dimensions; they do not replace the primary encounter or dictate interpretation.
- **1.15–1.9:** Anti-bias practices, contested claims handling, claim-genealogy guidance in Deep mode, expanded triggers (“athena go deep”, “go deep”, etc.), strengthened citation/provenance requirements especially in themes, refined Deep mode from graduate seminar pedagogy research (Seminar Guiding Questions, intellectual genealogy, seminar-memo digests), introduction of Standard vs Deep, portability improvements, elevation of citations/further-reading to core principles, initial museum adaptive guidance.
- **1.2 (2026-08-12):** Prior baseline.
